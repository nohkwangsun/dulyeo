# 공개 폴백 서명 키

`debug.keystore` (비밀번호 `android`, alias `androiddebugkey`)는 **누구나 볼 수 있는 공개 키**입니다.

- 저장소에 `ANDROID_KEYSTORE_*` 시크릿이 없을 때 APK를 서명하는 용도입니다. 이 키 덕분에 시크릿 없이도
  빌드마다 서명이 같아서 폰에서 업데이트 설치가 됩니다.
- 공개 키라서 이론상 누구나 같은 키로 서명한 APK를 만들 수 있습니다. 내가 올린 릴리스 링크가 아닌 곳에서 받은 APK는 설치하지 마세요.
- 더 안전하게 쓰려면 `scripts/make-keystore.sh`로 본인 키를 만들어 시크릿으로 등록하세요(README 참고).
  키가 바뀌면 폰에서 한 번 앱을 지우고 다시 설치해야 합니다.
